# Upgrade UI — 20 concept prompts

Built-in image generation, 2026-10-30. Concept previews, not production pixel sprites.

## Shared prompt

Create ONE landscape 16:9 game UI concept draft for a Korean pixel-art fantasy survivor roguelike upgrade selection. This is a visual design exploration, not a finished sprite sheet. Cohesive visibly pixel-art UI edges, bitmap-inspired readable Korean lettering, small crisp pixel icons, limited palette and flat fills, no blur glow, no modern glass UI. Very dim simple top-down dungeon battlefield. Keep SAME choice content across all concepts: '연쇄 번개' effect '연쇄 대상 +1', '다중 투사' effect '투사체 +1', '생명력 강화' effect '최대 체력 +10%'. If layout uses shared details show only selected choice details while other choices remain identifiable. Use title '레벨 업' where appropriate. Tiny reroll action '다시 뽑기 · 2회'. All labels concise and readable; omit redundant stats. Include a tiny unobtrusive concept number top-left. Avoid ornate parchment, excessive filigree, illegible microtext, photorealism. Full-screen actual interface draft, not device mockup, not reference collage. The key requirement is this DISTINCT layout:
